# CRUD API (TypeScript)

1. Copy .env.example to .env and change PORT if necessary.
2. Install dependencies:
   npm install
3. Development mode:
   npm run start:dev
4. Cluster mode (load balancer + workers):
   npm run start:multi
5. Production:
   npm run start:prod
6. Tests:
   npm test
7. Lint:
   npm run lint
